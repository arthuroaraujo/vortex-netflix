# Flixter

Aplicação web de catálogo de filmes e séries, desenvolvida com Vue 3 e TypeScript.

O Flixter permite que usuários pesquisem filmes e séries, visualizem informações detalhadas e mantenham uma lista pessoal de favoritos.

---

## Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Autenticação utilizando JWT
- Busca de filmes e séries
- Filmes em destaque na página inicial
- Página de detalhes do filme
- Exibição de pôsteres e informações do filme
- Adição de filmes à lista de favoritos
- Remoção de filmes dos favoritos
- Lista pessoal de favoritos
- Proteção das funcionalidades de favoritos para usuários autenticados
- Estados de carregamento com Skeleton
- Mensagens de erro e validação
- Confirmação antes da remoção de favoritos
- Interface responsiva
- Testes unitários do frontend
